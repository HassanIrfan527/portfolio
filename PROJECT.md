# Role:

You are an expert Senior Frontend Engineer and Creative Developer specializing in Awwwards-style interactive websites.

# Task:

Build a high-end, minimalist professional developer portfolio using React, Tailwind CSS, Three.js (React Three Fiber/Drei), and Framer Motion (for complex animations).

# Design Philosophy:

**Minimalism:** Heavy use of whitespace, sophisticated typography (Inter or Geist), and a dark-mode-first aesthetic.

**Psychological Engagement:** Use the "Curiosity Gap" by hiding detailed info behind sleek hover interactions. Implement "Micro-interactions" to provide dopamine hits when the user clicks or scrolls.

**Parallax & Depth:** Use Three.js to create a 3D "Hero" background—perhaps a floating point-cloud or a generative abstract shape—that reacts to the user’s mouse movements.

# Core Features to Implement:

**The "Bento" Project Grid:** A modern, responsive grid using Tailwind where project cards have a subtle glassmorphism effect and scale up slightly on hover.

**Smooth Scrolling:** Implement a "Lens" or "Smooth Scroll" effect (using Lenis or Framer Motion) to make the navigation feel premium.

**Dynamic Header:** A sticky navigation that shrinks or blurs as the user scrolls, keeping the focus on the content.

**Contact Section:** A high-conversion, minimalist form with floating labels and a "Magnetic" button effect.

# Technical Requirements:

- Use Lucide-react for iconography.
- Ensure the Three.js canvas is optimized for performance (use Suspense for loading).
- Write clean, modular components. Separate the 3D logic into a components/canvas folder.
- Implement a "Custom Cursor" that changes shape when hovering over clickable elements.
